# Personal Expense Tracker 💰

This is a small Python project I built to practice my programming skills. It helps me keep track of expenses, calculate total spending, and save expense records so I can access them again when I run the program.

## What it can do

- Add new expenses with a name and amount
- View all recorded expenses
- Calculate total spending
- Save expenses in a text file
- Load saved expenses when the program starts
- Handle invalid amounts and menu choices

## Built with

- Python 3
- File handling
- Lists and dictionaries
- Loops and conditional statements
- Exception handling

## How to run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal and run:

   `python expense_tracker.py`

4. Follow the menu to add and manage expenses.

## What I learned

While building this project, I practiced using Python loops, dictionaries, file handling, and exception handling. I also learned how to save data in a file and load it again when the program starts.
